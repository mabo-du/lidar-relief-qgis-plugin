# Wiki publishing

`Home.md` is the version-controlled source for the GitHub Wiki landing page.
The shipped `lidar_relief/USER_GUIDE.md` remains the canonical manual.

When publishing the GitHub Wiki, copy this landing page into the repository's
separate wiki Git repository. Its absolute guide links work in either location.
Do not duplicate the complete user guide: keeping one detailed source prevents
the installed help, repository documentation, and wiki from drifting apart.
